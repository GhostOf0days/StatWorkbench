The packaged Python engine contains its own `engine/THIRD_PARTY_NOTICES.md` and `engine/licenses/` collection, generated by `scripts/collect_backend_licenses.py`. Electron's distribution includes its Electron, Chromium, Node.js and other runtime notices. Those runtime files must remain in the packaged desktop application.
